# Reze-AI-Assistant

Стек
Язык — Python. Тут вообще без вариантов. Весь AI/ML экосистем живёт в питоне, все библиотеки для распознавания голоса, синтеза, клонирования — питон. Можно местами Node для веба или Rust/Go если захочется ускорить узкие места, но ядро — Python.
IDE — Cursor или VS Code. Cursor особенно затащит, потому что встроенный AI реально помогает с такими проектами. PyCharm тоже норм, если привык к JetBrains.
Компоненты по слоям
1. Wake word (отзывается на имя)
Picovoice Porcupine — стандарт индустрии, есть бесплатный тариф, можно натренить кастомное имя. Альтернатива — openWakeWord (опенсорс, бесплатно).
2. Speech-to-Text (слушает)
faster-whisper — оптимизированный Whisper от OpenAI. Локально, бесплатно, русский язык понимает топово. Для реалтайма можно прикрутить стриминговый вариант.
3. Мозг (LLM)
OpenRouter — норм выбор для старта, даёт доступ к куче моделей. Но честно: для русского языка GPT-4 или Claude через прямые API будут чуть качественнее. Если хочешь оффлайн и приватность — Ollama + Qwen 2.5 или Llama 3.1, но нужна видяха с 8+ ГБ VRAM минимум. Для tool calling (вызовы интернета, телеги и т.д.) — без вариантов нужна модель с function calling, OpenRouter это поддерживает.
4. Text-to-Speech с клонированием голоса (вот тут самое сочное)
Для аниме-голосов де-факто стандарт — RVC (Retrieval-based Voice Conversion). Огромное комьюнити, куча готовых моделей на HuggingFace, можно натренить свою на 10-30 минутах чистого аудио. Альтернативы:

XTTS-v2 от Coqui — клонирует голос из 6-секундного сэмпла, многоязычный, русский тянет
Bark — умеет в эмоции (смех, вздохи, разные интонации) прямо в синтезе
ElevenLabs — лучшее качество на рынке, но платно и в облаке

Для эмоций реально удобно комбо: RVC для тембра + что-то вроде Bark или эмоциональной модели для интонаций. Либо XTTS-v2, у него эмоции через референс-аудио задаются.
5. Telegram (отвечать вместо тебя)
Тут важный момент: тебе нужен user-аккаунт, не бот. Поэтому python-telegram-bot не подойдёт. Бери Telethon или Pyrogram — они работают через MTProto и логинятся как обычный пользователь.
⚠️ Честное предупреждение: автоответы с твоего акка — серая зона. Telegram может забанить за подозрительную активность, особенно если будешь часто отвечать в одном стиле или слишком быстро. Делай человекоподобные задержки, не спамь.
6. UI (на потом)
Когда дойдёшь — Tauri (легче Electron, на Rust под капотом) или просто веб-морда на FastAPI + React. Для нативного быстрого варианта — customtkinter или PyQt.
Архитектура
Не пихай всё в один скрипт. Делай модульно:
core/           # event bus, конфиги
audio/          # wake word, STT, TTS  
brain/          # LLM, промпты, контекст, память
tools/          # web search, telegram, погода и т.д.
integrations/   # внешние сервисы
ui/             # потом
Связь между модулями — через event bus или очередь (можно простой asyncio, можно Redis pub/sub если разрастётся). Так каждый кусок можно тестить отдельно и менять не ломая остальное.
Дорожная карта (как реально не сдохнуть)
Фаза 1 — голосовой цикл (2-4 недели)
Wake word → Whisper → OpenRouter → простой TTS (для начала edge-tts, он бесплатный и в браузерных голосах). Просто чтоб круг замкнулся: сказал → услышал ответ.
Фаза 2 — кастомный голос (2-3 недели)
Поднимаешь RVC локально, тренишь модель на сэмплах нужного аниме-голоса (понадобятся чистые WAV без музыки/шума, 15-30 минут хватит). Прикручиваешь к пайплайну.
Фаза 3 — инструменты (3-4 недели)
Function calling, веб-поиск, Telegram через Telethon. Тут самая сложная часть — нормально промптить модель чтобы она решала когда инструменты звать, а когда нет.
Фаза 4 — эмоции и UI
Эмоциональный синтез + дашборд.
